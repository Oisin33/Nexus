# Changelog

## [1.0.0], 2025-11

Initial release.

- BM25 index over language-aware code chunks
- Claude agent with four tools: search, read file, list files, generate docs
- Real SSE streaming (character-level, direct from Anthropic API)
- File tree sidebar with referenced-file highlighting
- File viewer with line-level highlighting linked to source citations
- Keyboard shortcuts (⌘K, ⌘\, Esc)
- Docker Compose setup with nginx for the frontend
